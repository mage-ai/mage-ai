Self-service password reset lets a user choose a new password without asking an
administrator. It applies to Mage accounts that have an email address and use a
Mage password. If your organization uses an external identity provider, reset
your password with that provider instead.

## Before you begin

Password reset is available in Mage Pro releases that include the feature.
Hosted Mage Pro deployments include the Mage-managed email infrastructure;
customers do not need to add email credentials or password-reset environment
variables to individual clusters.

To make the feature available, a Mage Pro administrator should deploy a Mage Pro
release that includes password reset.

## Reset your password

<Steps>

<Step title="Request a reset link">

On the Mage sign-in page, select **Forgot password?**, enter the email address on
your Mage account, and select **Send reset email**.

Mage shows the same accepted response whether or not the address belongs to an
account. This prevents the page from revealing which email addresses are
registered.

</Step>

<Step title="Open the email">

Open the message and follow the reset link. Each link expires after one hour and
can be used only once. If a link has expired or has already been used, request a
new one.

</Step>

<Step title="Set a new password">

Enter and confirm a password that satisfies the requirements shown on the page,
then select **Update password**. After the password changes, Mage invalidates all
existing sessions and all other outstanding reset links for the account. Sign in
again with the new password.

</Step>

</Steps>

## Email delivery and request limits

Password-reset email delivery is best effort. An accepted request means Mage has
accepted it for delivery; it does not guarantee that a message has reached the
inbox. Delivery can still be delayed or fail because of the email provider,
recipient server, spam filtering, or a service interruption.

Requests are limited per recipient email address to 3 per hour and 5 per day.
Attempts count toward these limits even when delivery does not complete. If a
message does not arrive, check the spam folder and wait before requesting another
link. If delivery continues to fail after the request limit resets,
[contact Mage Support](https://www.mage.ai/help).

## Troubleshooting

| Issue | What to do |
| --- | --- |
| **Forgot password?** is unavailable | Ask an administrator to confirm that a Mage Pro release with password reset is deployed. If it remains unavailable, [contact Mage Support](https://www.mage.ai/help). |
| The email does not arrive | Check the spam folder and confirm that the account uses the submitted email address. Because delivery is best effort, wait before requesting another link, then [contact Mage Support](https://www.mage.ai/help) if the issue continues. |
| The link is invalid or expired | Request a new link. Links expire after one hour, are single-use, and are invalidated when another link successfully changes the password. |
| Too many requests | Wait for the hourly or daily per-recipient limit to reset. |
