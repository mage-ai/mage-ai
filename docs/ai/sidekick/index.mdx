AI Sidekick brings an AI assistant into your Mage Pro workspace. Use it to
ask questions about the page you are viewing, inspect pipeline context, generate
or update code, debug failures, and run longer agent tasks without leaving Mage.

Use AI Sidekick to:

- ask about the current page, selected pipeline, block code, logs, outputs, and
  project files
- create pipeline blocks, refactor existing code, and apply requested changes
  with Mage context
- use logs, block outputs, and pipeline metadata to understand errors and
  suggest fixes
- let the Mage agent inspect resources, call tools, and report progress during
  longer workflows

## Open AI Sidekick

Open AI Sidekick from Mage Pro. You can also open the standalone chat at
`/ai/chat` or `/apps/ai/chat` in an authenticated workspace.

AI Sidekick is available to users with the Editor role or higher.

## What AI Sidekick Can Use As Context

AI Sidekick can work with the context Mage already has about your workspace,
including:

- the current page title and URL
- visible non-chat text on the page
- selected pipelines and blocks
- block code, block outputs, and logs
- pipeline run state and recent execution details
- files or images you attach to the chat session
- project files that the configured agent tools are allowed to read

This means you can ask questions like:

```text
Explain why this block failed.
```

```text
Update this transformer to validate the required columns before exporting.
```

```text
Create a pipeline that loads customer data, cleans emails, and exports the result.
```

## Chat Sessions

AI Sidekick keeps conversations in sessions. The sidebar lets you:

- start a new chat
- search active chat history
- view archived chats
- load older chats with **Show more**
- archive a chat
- reopen a chat from the current workspace

Mage remembers the selected chat and sidebar view for the current workspace, so
you can refresh or reopen AI Sidekick without losing your place.

## Attach Files

Attach files to give AI Sidekick more context for the current chat. Attachments are
scoped to the chat session and can be referenced by the agent while it works.

Default attachment limits are:

| Limit | Default |
|---|---:|
| Maximum file size | 10 MB |
| Maximum files per session | 20 |
| Maximum total attachment size per session | 50 MB |

Workspace administrators can override these limits with:

```bash
MAGE_CODEX_CHAT_ATTACHMENT_MAX_BYTES=10485760
MAGE_CODEX_CHAT_ATTACHMENT_MAX_COUNT=20
MAGE_CODEX_CHAT_ATTACHMENT_MAX_SESSION_BYTES=52428800
```

When the agent returns a project-local PNG, JPEG, GIF, or WebP path, Mage can
render the image inline in the chat transcript.

## Execution Settings

Use the chat settings menu to choose how the agent should run for the current
chat:

- **Speed** controls whether the chat uses the standard or fast execution path.
- **Reasoning** controls how much reasoning effort the model should use.

Use lower reasoning for quick questions and higher reasoning for complex code
changes, multi-step debugging, or tasks that need deeper project analysis.

## Common Workflows

### Explain The Current Page

Ask AI Sidekick what you are looking at when you are on a pipeline, run, log, block,
or settings page.

```text
What am I looking at, and what should I check next?
```

### Debug A Failed Block

Open the failed block or run logs, then ask AI Sidekick to explain the failure and
suggest a fix.

```text
Why did this block fail? Suggest the smallest safe fix.
```

### Generate A Pipeline Or Block

Describe the data source, transformations, destination, schedule, and any
constraints you care about.

```text
Create a daily pipeline that loads Stripe charges, removes test records, and
exports clean revenue data to Snowflake.
```

### Refactor Existing Code

Ask AI Sidekick to update code in place while preserving the pipeline contract.

```text
Refactor this transformer to use Polars and keep the same output columns.
```

### Work With Project Files

Ask AI Sidekick to inspect project files, explain how a pipeline is organized, or
make targeted changes.

```text
Find where this pipeline reads database credentials and explain how they are used.
```

## Project Context

For deeper project-aware answers, AI Sidekick can reference project files and
related workspace context that the configured agent tools are allowed to read.
Use project context when you want answers grounded in your actual repository
structure, pipeline code, naming conventions, and configuration.
