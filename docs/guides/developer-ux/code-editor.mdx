## Adding blocks made easy

You can quickly add blocks of code to your pipeline with these methods:

<AccordionGroup>
    <Accordion title="Drag blocks from the file browser and drop it on the pipeline" icon="dragon" iconType="duotone" defaultOpen>
        <Note>
            **Supported block type directories:** `callbacks`, `conditionals`, `custom`, `data_exporters`, `data_loaders`, `dbt`,
            `dbts`, `markdowns`, `scratchpads`, `sensors`, and `transformers`

            Version 0.9.64 or greater is required to add `callback` and `conditional`
            blocks from the file browser.
        </Note>

        1. Open the file browser on the Pipeline Editor page.
        1. Click a block file and keep holding down.
        1. Drag the block file onto the center of the page (the Notebook area).
        1. Release the button and it’ll be added to the pipeline.

        <Frame>
            <p align="center">
                <img
                    alt="Drag blocks from the file browser and drop it on the pipeline"
                    src="https://mage-ai.github.io/assets/dev-ux/code-editor/drag-block.gif"
                />
            </p>
        </Frame>
    </Accordion>

    <Accordion title="Add the next outcome" icon="wand-magic-sparkles" iconType="duotone">
        <ProOnly source="add-outcomes" />

        When workspace AI is enabled and Sidekick is not disabled for your account:

        1. Choose where the new work should appear:
           - In an empty notebook, use the embedded **What should happen?** composer.
           - At the end of a notebook, use the persistent embedded **What should happen next?**
             composer.
           - Between blocks, hover over the insertion space to reveal **Add**, then click it to open
             the composer.
        2. Describe the result you want, such as
           `Remove duplicate customer rows and summarize them by region`.
        3. Click **Generate** or press <kbd>Enter</kbd>.
        4. Follow the response and progress in Sidekick.

        Describe the outcome rather than choosing a block type. The composer sends your original
        request and the selected insertion point to Sidekick. Sidekick may answer a question or ask
        for clarification without changing the notebook. When changes are needed, it may create,
        update, remove, or reorganize one or several blocks to produce the result. Sidekick also
        shows generation errors. The request uses the active Sidekick conversation. While a request
        is being handed off, **Add**, the prompt, and **Generate** are disabled; wait for the
        handoff to finish before submitting another outcome from that composer.

        Between blocks, the composer opens as a viewport-aware popup without shifting notebook
        content. Empty and terminal composers remain embedded in the notebook.

        Open **More** for **Reuse code**, **Templates**, **Data product**, **Markdown**, or
        **Scratchpad**. **Data product** opens the global data products browser.

        Use **Code** immediately to the left of **More** to insert a blank **Python**,
        **SQL**, or **R** transformer block, a **dbt** run block, or an **AI block**. The AI block
        option is available only while workspace AI is enabled.

        When workspace AI is disabled or you disable Sidekick for your account, the original
        block creation controls appear instead of the composer.
    </Accordion>

## Notes on editing pipelines

<Warning>
    Avoid opening and editing the **same pipeline in multiple browser tabs or windows** at the same time.
    Changes from one tab may overwrite changes from another.
</Warning>

Tips to stay safe:

- Edit a pipeline in **one tab only**.
- If you need to monitor the pipeline elsewhere, use another tab in **read-only mode**.
- Close extra editing tabs if opened by mistake.

---

### Collaboration best practices

If multiple users need to develop the **same pipeline**:

- Use **[Workspace mode in Mage Pro](/guides/developer-ux/workspaces)**, which provides:
  - Isolated environments per user or team.
  - Safe collaboration without overwriting each other’s changes.
  - The ability to merge updates back into shared pipelines.

This ensures smooth teamwork and prevents conflicts when more than one person is editing.

## Add new block v2

<ProOnly source="add-new-block-v2" />

In Mage Pro, Add new block v2 provides an outcome-first creation flow in the Pipeline Editor
(`/pipelines/[pipeline_uuid]/edit`) when workspace AI is enabled and Sidekick is not
disabled for your account. In an empty
notebook, start with the embedded **What should happen?** composer. After blocks
exist, use the persistent embedded **What should happen next?** composer at the
end of the notebook. To insert work
between blocks, hover over the insertion space to reveal **Add**, then click it to
open the composer.

Describe the result you want instead of selecting a block type, then click
**Generate**. The composer sends your original request and selected insertion
point to Sidekick. Sidekick may answer a question or ask for clarification
without changing the notebook. When changes are needed, it may create, update,
remove, or reorganize one block or multiple blocks. Sidekick owns generation
progress and errors. The request uses the active Sidekick conversation. While a
request is being handed off, **Add**, the prompt, and **Generate** are disabled,
so another outcome cannot be submitted from that composer until the handoff
finishes.

Only the between-block composer opens as a viewport-aware popup; the empty and
terminal composers remain embedded in the notebook. Open **More** for
**Reuse code**, **Templates**, **Data product**, **Markdown**, or **Scratchpad**.
**Data product** opens the global data products browser.

Use **Code** immediately to the left of **More** to insert a blank
**Python**, **SQL**, or **R** transformer block, a **dbt** run block, or an
**AI block**. The AI block option is available only while workspace AI is enabled.

When workspace AI is disabled or you disable Sidekick for your account, the original
block creation controls appear instead of the composer. To change your account preference,
open **Workspace preferences**, find **Account settings**, toggle **Disable AI Sidekick**,
then click **Save**. This preference applies only to your account.

To add existing block files instead of creating a new implementation, drag them
from the file browser into the notebook.

## Code and output side-by-side view

Run code and see its output right next to where you’re writing.

This makes it so that you don’t have to keep scrolling down every time you make a code change
and want to see its results.

For table outputs, click a column header to sort the preview or use the filter
icon beside the header to filter rows by column value. Use **Columns** to search
for columns and choose which ones appear in the preview. **Deselect all** hides
every column, while **Reset** restores the initial selection. Wide DataFrame
previews initially show the first 100 columns, and the picker can reveal any of
up to 1,000 sampled columns. These controls are temporary preview tools and don’t
change the underlying block output.

In Mage Pro only, open a code block’s **…** menu and select **Clear output** to
delete its saved notebook output while leaving other blocks’ output unchanged.
The output stays cleared after refreshing the page. Run the block again to
create fresh output for display and downstream blocks.

<Frame>

To enable this feature:

1. Go to your [project settings](http://localhost:6789/settings/workspace/preferences).
1. Enable the feature named <b>Notebook block output split view</b>.
1. Open the edit view of a pipeline.
1. Under the header menu named <b>View</b>, click the option <b>Show output next to code</b>.
