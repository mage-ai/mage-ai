## List Agents

```http
GET /api/agents
```

Optional query parameters:

- `_limit`: Maximum number of agents to return.
- `_offset`: Number of agents to skip.

```json
{
  "agents": [],
  "metadata": {
    "count": 0,
    "results": 0,
    "has_more": false
  }
}
```

## Get Agent

```http
GET /api/agents/{agent_uuid}
```

Returns one `agent` object.
