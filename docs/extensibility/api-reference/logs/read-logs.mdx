---
title: "Read logs"
api: "GET /api/pipelines/:pipeline_uuid/logs"
---
```GET /api/pipelines/:pipeline_uuid/logs```

<ParamField path="pipeline_uuid" type="string" required>
  Pipeline UUID of the logs.

  Example: `example_pipeline`
</ParamField>

<ParamField query="_limit" type="integer">
  Maximum number of logs to be returned in the API response.

  Example: `20`
</ParamField>

<ParamField query="_offset" type="integer">
  Read logs after N number of logs, where N equals `_offset`.

  Example: `10`
</ParamField>

<ParamField query="start_timestamp" type="integer">
  Read logs on or after a specified timestamp.

  Example: `1677648116`
</ParamField>

<ParamField query="end_timestamp" type="integer">
  Read logs on or before a specified timestamp.

  Example: `1678252916`
</ParamField>

<ParamField query="level[]" type="array of strings">
  Read logs matching one or more log levels.

  Example: `INFO`
</ParamField>

<ParamField query="source_category[]" type="array of strings">
  Read Mage Pro OpenSearch-backed logs from one or more source categories.
  Accepted values are `user_code`, `mage_scheduler`, `executor`,
  `connector_library`, `kubernetes`, `system`, and `unknown`.

  Example: `user_code`
</ParamField>

<ParamField query="exclude_source_category[]" type="array of strings">
  Exclude Mage Pro OpenSearch-backed logs from one or more source categories.
  To hide infrastructure logs, pass `mage_scheduler`, `executor`, `kubernetes`,
  and `system`.

  Example: `kubernetes`
</ParamField>

Source category filters require Mage Pro OpenSearch-backed log search. When the
API falls back to disk logs, responses with active source filters include
`fallback_from_disk: true`, `source_filters_applied: false`, and
`source_filter_fallback_reason: "opensearch_unavailable"`. Legacy OpenSearch
documents are classified from conservative structured fields when possible;
unclassified entries remain `unknown` and are included in unfiltered results.
Unsupported source category values return no OpenSearch-backed rows for that
request instead of being ignored.

<ParamField query="hide_health_check" type="integer">
  Pass `1` to hide scheduler health-check log entries.

  Example: `1`
</ParamField>
